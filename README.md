# 📊 Customer Analytics Dashboard – SWYNEX Task 3

## 📌 Project Overview

As part of my **SWYNEX internship**, Task 3 focused on creating an interactive Customer Analytics Dashboard using **Microsoft Excel**.

The objective was to transform cleaned customer data into meaningful visual insights through KPI metrics, charts, and customer purchasing analysis.

## 🎯 Project Objectives

- Analyze customer purchasing behaviour.
- Identify high-performing product categories.
- Compare customer spending across cities.
- Understand purchasing channel performance.
- Visualize customer demographics.
- Present important business insights in a clear dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables and data analysis
- Excel charts and data visualization
- KPI calculations
- Data filtering and formatting

## 📈 Dashboard Features

The dashboard includes:

| Feature | Description |
|---|---|
| Total Customer Records | Displays the number of customer records |
| Total Purchase Value | Shows the overall recorded purchase amount |
| Average Purchase Value | Calculates average recorded spending |
| Average Customer Age | Displays the average age of customers |
| Category Analysis | Compares purchase amounts across categories |
| City Analysis | Identifies cities with higher purchase amounts |
| Channel Analysis | Compares Mobile App, Online, and In-store purchases |
| Gender Analysis | Visualizes customer distribution by gender |

## 🔍 Key Insights

- **Total customer records:** 125
- **Total recorded purchase value:** NPR 3,383,690
- **Average purchase value:** Approximately NPR 31,043
- **Average customer age:** Approximately 43.5 years
- **Top-performing category:** Beauty
- **Highest-spending channel:** Mobile App

*Note: Purchase metrics are calculated using available recorded purchase values.*
